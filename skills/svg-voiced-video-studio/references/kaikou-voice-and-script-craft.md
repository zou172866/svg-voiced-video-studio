# 口播人话韵律、防切尾音与混音工艺手册（吸收自 kaikou）

在编写口播逐字稿、校准古今多音字与数字读法或排查 `GPT-SoVITS` 听感生硬时读取本文件。本文件是配音参数的唯一出处，数值与 `scripts/synth_voiceover_template.py` 保持一致。

---

## 一、口播稿人话铁律与五类去 AI 味扫描（跑 `scripts/lint_script.py` 自动核查）

1. **双音节标准韵律词优先（70%～85% 比例）**
   - 汉语口语天然是两个字一拍。AI 写稿爱用书面单字（已、需、仅、均、若、则、其、该、未、即可），配音出来一字一顿像念公文：
     - `已支持 / 仅需 / 若不干净则需重录` → 改为 `已经支持 / 只需要 / 如果不干净就需要重新录`
   - 保留约 15%～25% 自然口语单字（如 `直接用` 的 `用`），避免机械全换双字。
2. **句子成分说完整，标点间不超过 24 字，禁止圆括号补充**
   - 口播靠耳朵单向接收，不能省主语、量词和连接词；两个标点之间控制在 `22～24` 字以内；
   - 台词里禁止出现 `（一种基于…的工具）` 这类念不出来的圆括号补充，必须拆进短句或删掉。
3. **长短句穿插（句长变异系数 CV ≥ 0.25）**
   - 同一幕连续四五句长度相近会形成催眠感；长句讲完事实后，紧跟一句 `6～10` 字的短句或自问句把节奏挑起来。
4. **冷开场禁区与避免提前收尾**
   - 前 3 秒直接抛冲突、数字或反常事实，严禁 `大家好 / 本期视频我们将 / 在开始之前先了解` 报幕式开场；
   - 正片前中段严禁说 `最后`、`总之`，防止观众误判结束划走。
5. **五类口播 AI 指纹清零（风骨层）**
   - **假共情**：禁 `我知道你最近肯定很… / 你是不是也有这种感觉 / 今天这条视频是给那些…`，改用具体踩坑事实；
   - **假深刻**：禁 `恰恰相反 / 这反而是…的地方 / 正是因为…所以才…`（自检法：删掉 `恰恰 / 反而` 意思不变就直接删）；
   - **自我加权**：禁 `我必须很认真地说 / 这一段你一定要听完 / 今天就把…一次说透`，好观点直接说，不提前清嗓子；
   - **万能模板与套话收尾**：禁 `说白了 / 本质上 / 换句话说 / 一句话总结 / 在某种意义上 / 以上就是本期内容 / 希望对你有帮助 / 感谢观看`；
   - **三连排比堆砌**：禁连续 `≥ 3` 个同构短分句（如 `不躲，不藏，不绕`），只留最具体的一句。
6. **客观评测与工具拆解口播四准则 + 线性时间选型收束**（依据：受众共同基础理论与时间顺序象似性；失效边界：快手等纯下沉白话简介除外）
   - **保留受众通用计量词并全片统一**：面向开发者或工具用户的实测稿，保留圈层已普及的标准单位（如 `token`、`fps`）并确保全片前后一致，不强译为含糊外行词；产品设置项优先采用界面原生中文说法（如 `思考程度调高`）；
   - **直呼对象与信源真名**：首幕直接点名权威评测机构或一手出处，正片直呼产品真名，不加 `老大哥 / 老旗舰 / 破网站` 等自媒体情绪化标签；
   - **砍掉转段报幕短句**：段首直接进数据或判断，删去 `先看综合表现 / 接下来看第二点` 等报幕废话；
   - **正向给操作设置，按时间线收束选型**：结尾直接告诉观众日常怎么设参数，不用 `免得账单超支` 类反向焦虑警告；若选型含限时折扣或政策窗口，严格按 **「当下窗口期怎么选 → 窗口期后日常高频怎么选 → 重要与大工程怎么选」** 时间先后推进，不倒叙。

## 二、`{念法=>字幕}` 单行双轨正音与多音字校准

一份文稿即可同时驱动精准发音与原字字幕，无需把屏幕上的正确汉字改成错别字：

- **行内双轨写法**：在文本中直接写 `{给TTS念的同音正音字=>屏幕字幕显示的原字}`，例如：
  - `湖中{焉德=>焉得}更有此人`（锁死二声 `yān dé`，防读轻声）
  - `更有{痴四=>痴似}相公者`（锁死平舌 `chī sì`，防读翘舌 `shì`）
  - `{抢饮=>强饮}三大白而别`（锁死三声连读变调 `qiáng yǐn`）
- **JSON 字段双轨写法**：在 `scenes_source.json` 的台词对象中同时写 `text`（原字字幕）与 `ttsText`（正音读法）。
- **合成前必跑筛查**：运行 `python scripts/lint_script.py 稿件路径`，逐条核对输出的重点多音字清单。

### 数字、货币与英文读法

- 合成脚本调用 [zh_textnorm.py](../scripts/zh_textnorm.py) 自动把配音轨上的数字转成中文读法，字幕原文不变：`$12,400` → 一万两千四百美元，`37%` → 百分之三十七，`3.2万` → 三点二万，`2024年` → 二零二四年，`1:1` → 一比一，`75～110` → 七十五到一百一十，`2个` → 两个。
- 已知取舍：`10:30` 这类钟点也会读成比例；产品型号、电话号码等需要逐位读或保留英文时，用 `{念法=>原文}` 手动锁定（手动标注优先于自动转换）。整稿不想转换时加 `--no-num-normalize`。
- 英文词（`MRR`、`SaaS`、`TrustMRR`、`Carbon`）原样送入模型时，合成脚本会自动把紧跟英文词后的中文全角 `，` 转为英文 `, `，防止 `LangSegmenter` 吞掉停顿导致跳读；纯中文录音微调出的 GPT-SoVITS 音色遇到词首美式送气 `/t/`（如 `token`）极易发成塞擦音「抽坑」，固定用 `{偷肯=>token}` 双轨正音（`PDF` 用 `{P D F=>PDF}`，句尾易丢鼻音的 `Neon` 用 `{尼昂=>Neon}`），并在编码视频前用 `read_file` 逐幕真耳复听各 `.mp3` 核准。

## 三、多遍择优、防切尾音与语义停顿表

### 1. 为什么句尾容易像“字只说了一半”及四道根治法
1. **按标点物理拆句，句尾统一收句号**：`to_tts_clauses` 在 `；：——` 处拆开并插入 `0.18s` 气口，在 `。！？` 处拆开并插入 `0.30s` 气口；不足 4 个字的碎句并入相邻分句（问号、感叹号语气保留）。送入模型的每个分句句尾收为 `。！？`，避免模型以为后面还有话而在半空收声。
2. **收声阈值下探至 `-46 dB` + 余弦淡出**：找开口用 `-38 dB`（前留 `40ms` 余弦渐入，绝不吃掉声母辅音）；找收声放宽至 `-46 dB`，把尾字的气声完整保留下来，句尾留 `160ms` 余弦淡出。若某遍结尾 `60ms` 内电平陡降（一刀切坏例），多遍打分器会自动扣分淘汰。
3. **多遍生成择优（`--takes 3` 或 `4`）**：同一句换不同随机种子生成多遍，综合 **语速防跳字区间 + 句尾不截断 + 与前一句基频音高（F0）平顺衔接** 自动挑出最自然的一遍。
4. **响度统一**：每个分句按 `ITU-R BS.1770` K 加权响度拉到 `-18.5 LUFS`，峰值上限 `-1.5 dBFS`，最大增益 `+12 dB`。

### 2. 合成预设（`--preset`）

| 预设 | 每幕前置 | 每幕尾留 | 默认句间停顿 | 适用 |
| :--- | :--- | :--- | :--- | :--- |
| `long`（默认） | `0.95s` | `1.45s` | `0.52s` | 模式 A、B 横屏哲思长片 |
| `short` | `0.30s` | `0.60s` | `0.42s` | 模式 C 竖屏 75～115 秒快解说 |

单幕可在 JSON 里用 `leadInSec`、`tailOutSec` 覆盖，单行可用 `pauseAfterSec` 覆盖。

### 3. 语义停顿参考表（按意思定停顿，相邻句微错开 `±0.025s`）

| 语义关系 | 建议听感空白秒数 | 适用位置 |
| :--- | :--- | :--- |
| 同层意思紧接 / 自问紧接自答 | `0.34s ～ 0.40s` | 问句后立刻揭晓、上下半句顺承 |
| 普通句与句之间 | `0.43s ～ 0.48s` | 常规叙事推进 |
| 同一幕内换一层意思 | `0.50s ～ 0.56s` | 举完例子转入分析 |
| 段落收束 / 核心判断落地 | `0.62s ～ 0.75s` | 金句、核心论断说完后留给观众消化 |
| 跨幕大转折 | `0.90s ～ 1.20s` | 章节切换、视角翻转 |
| 终幕个人结束语收尾 | `4.50s ～ 5.50s` | `以不休止的追问，找到鲜活的自我；在有限的共识里，达成无限的可能。` 播完后的留白余韵 |

## 四、配音健康检查、按句缓存、卡点音效与 `-14 LUFS` 母带

1. **启动前体检与按分句哈希断点续合**
   - 可先运行 `python scripts/synth_voiceover_template.py --gpt-sovits-dir … --check-only` 秒级检查音色权重、参考音频、预训练底模、CUDA 与 `ffmpeg`；
   - 合成自动将每个分句的最优 take 按 `SHA-256(分句文本 + 语速 + takes + 音色权重)` 缓存在工程 `out/.tts_cache/`。长稿中途中断或修改单句台词重跑时，未变分句秒级复用；强制全量重算加 `--force-resynth`。
2. **动态闪避底乐与避让人声的卡点音效（[sfx_synth.py](../scripts/sfx_synth.py)，`--sfx auto | cues | none`）**
   - **底乐闪避**：按 `35ms` 快起、`420ms` 慢回包络跟随器压低约 `10 dB`，让出 `1～4 kHz` 人声频段；
   - **音效时间与避让纪律**：音效时间直接由 `scenesData.json` 的幕起点与强调词时间戳推出，不手写秒数：
     - `whoosh`：峰值落在 `0.70 × 时长` 处，自动提前 `0.04s`（约 2～3 帧 J-cut）对准切点（模式 C 每幕非空切点轻配，模式 A/B 仅在跨大章时轻配）；
     - `tick / pop / chime`：模式 C 数字登场前配稀疏 `tick`，`pop / chime` 严格放在句末语义停顿处（`endSec + 0.04s`），自动避开句首前 `80ms` 爆破辅音；若非切点音效与人声重叠，自动衰减 `-6 dB`；
     - `impact`：全片严格限制 `≤ 2` 个，且只准落在核心结论后的停顿空白处；也可在场景 JSON 传 `"sfxCues": [{"at": "cut"|"emphasis:0"|秒数, "kind": "pop"|"chime"|"impact", "gain": 0.25}]`。
3. **成片母带统一 `-14.0 LUFS`（`48kHz` 双声道）**
   - `voice + ducked_pad + sfx_bus` 合流后经 `ITU-R BS.1770` 母带拉齐至 **`-14.0 LUFS`**，前瞻软限幅锁死真峰值 **`≤ -1.2 dBTP`**，编码为 `48kHz` 立体声 `mixed_master_ducked.mp3`，满足抖音、B 站、小红书、视频号、快手响度标准，并通过 `scripts/inspect_video.py` 终检。
4. **单句氛围人声滤镜（`scripts/voice_fx.py`）**
   - `canyon`（空谷回响）、`tape`（老式磁带机）、`water`（水下包裹感）：只在点睛的 1～2 句台词项加 `"fx": "canyon"`，切勿全片通挂。
