### 2. 封面主标层级、红焦点与去噪五道铁律（v6）
1. **主标必须有强弱层级（全模式默认：`1 个超大钩子 + 1～2 行小一号说明`）**：
   - 严禁把 `3～4` 行字做成完全相同的字号连成一整句（`180px` 手机缩略图上读不出重点）；
   - **`hook`（1 行超大钩子）**：字号为说明行的 **`1.6×～2.0×`**，直接放全片最硬的数字或专有名词（如 `*19*个指令`、`月收*$12,400*`、`*agy-cmd*`），单行视觉宽度严格 `≤ 5.6 em`（让巨大字号撑满栏宽）；
   - **`sublines`（1～2 行小一号说明）**：交代反差处境或价值结果（如 `反重力藏起来了` / `1个Skill自动调`），纯汉字每行 `≤ 7` 字、混排 `≤ 7.2 em`，字号自适应视口防断行；
   - （仅兼容旧 JSON 时允许传入 `headline_lines`，脚本会自动提示升级为 `hook` + `sublines`。）
2. **朱砂红焦点只给信息，严禁给口号或空动词**：
   - 红色只标在**具体数字或核心专有名词**上（如 `*19*`、`*agy-cmd*`、`*$12,400*`），严禁标在「直接帮你解决」「彻底讲透」「一定要看」这类无信息量动词/口号上；
   - `render_4covers_template.py` 已废除“默认把最后一行变红”的旧逻辑：优先高亮 `hook` 中 `*标注*` 的信息词，全片封面严格遵守**单一朱砂红焦点**（无红框、无红底按钮、无红眉题）。
3. **去换行连读与事实边界核查**：
   - 封面不加句末标点；把 `hook` 与 `sublines` 去掉换行连成一句通读：确认主语唯一未串味、遮住正文陌生人能独立看懂主题、禁用抽象包装废词（底层逻辑/认知觉醒/爆款密码/方法论/真相）；
   - 假设推演类数字严禁写成既成事实。
4. **开放式双栏与彻底去噪（消灭框套框与制作参数）**：
   - **零框套框、零实心底**：底部/右侧两组对照数据之间**只用一根 `1px` 细竖线（横版为细横线）隔开**，不加外框、不铺黑块、不铺 `paper_deep` 实心底块，让暖宣纸面一气贯通；
   - **彻底删光制作参数与英文装饰**：封面严禁出现 `4K · 60FPS`、`4:3 FEED`、`16:9 · 4K 60FPS`、`01:25 ▶`、`VISUAL ESSAY`、`OPEN SOURCE ROUTER` 等制作参数或装饰英文；顶部最多只留 1 处极短中文眉题（如 `反重力自动路由`，也可留空保持极致呼吸感）。
5. **封面与正片共用同一展示字体 + 拉丁零散开 + `180px` 验真**：
   - 模式 C 封面与正片全程统一 `Source Han Sans CN Heavy`（900）；模式 A/B 封面与正片全程统一衬线体（`600` 无伪粗，拉丁字母自动包裹匹配拉丁衬线并锁 `letter-spacing: 0` + `pangu_space()`）；
   - 渲染固定加 `--qa-sheet` 输出 `封面_手机双列180px缩略图检验表.png`，实测 `180px` 下 1 秒读出超大钩子。

## 二、五平台标题字数硬限、纯文字排版与专属简介规范

### 0. 生产文档纯文字、去引号与专属结束语硬规则（重中之重，本 Skill 中这些规则只在此处定义）
- 只保留纯文字与空行分段，严禁使用复杂的 Markdown 格式：不要标题井号、不要加粗星号、不要反引号、不要表格、不要分割线、不要 Emoji 数字图标，直接用自然文字分行，确保复制粘贴到平台后台时零多余符号。
- 严禁滥用引号：标题、简介、话题标签、置顶评论一律不要用反引号或双引号包裹，正文里除书名篇名必要的书名号外，尽量少用双引号和直角引号，不要给普通概念词套引号。
- 原字保留创作者专属结束语：哲思与人文视频最后一镜（终幕题词与结尾配音字幕）固定保留创作者个人结束语：以不休止的追问，找到鲜活的自我；在有限的共识里，达成无限的可能。严禁删改、拆散原意或替换成其他鸡汤收尾。
- 所有文案禁用「不……而……」「不是……而是……」「并非……而是……」句式，禁用 Emoji。

### 1. B 站（哔哩哔哩）
- **投稿标题**：`≤ 80` 字符，交代具体人物处境/测试锚点 + 反常识核心追问（给 `2` 个备选，首项标推荐）。
- **视频简介**：
  - `2～3` 句话高密度核心梗概；
  - **精确到秒的空降章节时间轴（`00:00` 格式）**：直接使用合成脚本输出的 `out/chapters.txt`（按 `60fps` 真实累加帧数计算），严禁手估编造秒数；
  - 引用典籍 / 数据来源 / 适用边界说明；
- **投稿标签**：`8～10` 个精准垂类词；
- **置顶首评**：围绕正片核心测试或追问设计 `1` 个具体可回答的评论互动问题。

### 2. 小红书视频
- **视频标题**：含标点 **严格 `≤ 20` 字符**（逐字核数并标明字符数，给 `2～3` 个备选）。
- **发布正文**：
  - 开头 `2` 句真实处境切入；
  - 中段 `3` 条结构化看点提炼；
  - 结尾 `1` 句具体处境提问 + `5～6` 个搜索长尾 `#标签`；
  - **排雷红线**：严禁出现 `.com / .io` 外链、微信号或站外导流暗语。
- **置顶首评**：轻量行动打卡或共鸣追问。

### 3. 抖音
- **作品标题**：含标点 **严格 `≤ 30` 字符**（给 `2` 个备选）。
- **作品描述**：两句话高信息密度简介 + `5` 个 `#话题标签`。
- **置顶首评**：引导观众跳转至全片最具张力的精确分秒段落（如“建议看到第 01 分 59 秒……”）并留下观点。

### 4. 微信视频号
- **作品标题**：含标点 **严格 `≤ 30` 字符**。
- **作品描述**：两句话沉静走心提炼（契合熟人社交圈“赞与推荐”转发心理）+ `5` 个 `#话题标签`。
- **置顶首评**：提炼全片最值得收藏转发的一句核心金句收尾。

### 5. 快手
- **双列推荐短标题**：含标点 **严格 `≤ 18` 字符**（纯大白话直给冲突与数字，严禁英文缩写与生僻黑话，给 `2` 个备选）。
- **作品描述**：接地气、实在算账式或掏心窝大白话描述 + **最多 `4` 个 `#话题标签`**（快手平台硬上限只能添加 4 个话题，严禁超出）。
- **置顶首评**：老铁唠嗑式直白互动提问。
