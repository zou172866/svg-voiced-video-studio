# 五平台发布文案与四尺寸防裁切封面硬性规范

在拟定封面文字、渲染四尺寸封面或编写多平台发布文案包时读取本文件。

---

## 一、四尺寸视频封面与 `≤ 6 字/行` 硬规则

### 1. 四张必交封面规格与平台分工
| 文件名 | 物理像素 (`@2x`) | 适配平台与展示位 | 版式与防裁切硬要求 |
| :--- | :--- | :--- | :--- |
| `封面_竖屏9比16_抖音视频号版.png` | `1080 × 1920` | 抖音 / 快手 / 视频号个人主页竖版封面 | **上下各留白 `≥ 240px`**（逻辑 `540×960` 下 `padding: 136px 42px`），全部文字与核心图形严锁在正中央 `3:4` 安全区内，主页宫格裁切零切字 |
| `封面_信息流3比4_小红书视频号版.png` | `1080 × 1440` | 小红书视频 / 快手双列瀑布流 / 视频号独立 `3:4` 封面 | 大字号主标题 + 中段极简几何矢量图 + 底部双栏对照印章 |
| `封面_横版4比3_B站抖音推荐版.png` | `1440 × 1080` | B 站手机双列 `4:3` 推荐流 / 抖音横版 `4:3` 封面位 | 左大字（`white-space: nowrap` 防断行）+ 右上下双格核心账本，小缩略图一眼看清 |
| `封面_横屏16比9_B站双封面版.png` | `1920 × 1080` | B 站网页端宽屏封面 / 抖音横版全屏推荐位 | 瑞士非对称 `7:5` 分栏（左主标题与导语，右几何示意图与双栏对照表，表头禁折出单字孤行） |

### 2. 封面大字三道硬检
1. **逐行视觉字宽硬限（中西混排等宽折算）**：默认 `3～4` 行，纯汉字每行严格最多 `6` 个字；含英文专名或数字时按视觉全角字宽校验（汉字 `1.0 em`、大写字母 `0.68 em`、小写字母与数字 `0.55 em`），**单行视觉宽度严格 `≤ 6.2 em`**（如 `对比Carbon` 折算 `5.43 em` 直接合法放行，无需删去产品真名）。不可拆超长专名可用 `render_4covers_template.py --allow-7` 放宽至 `7.2 em`，脚本自动缩小标题字号 `8%`；`4` 行标题自动微调字号以适配安全区高度。抖音个人主页两行索引短标题同样遵守 `≤ 6.2 em`。
2. **去换行连读检查**：封面上不加句末标点，写完后必须去掉换行连成一句通读：
   - 确认主语唯一且未串味（严禁把“作者的经历”直接挨着“对别人的负面判断”导致读者把作者读成被批评对象）；
   - 遮住发布正文与聊天上下文，确认陌生人仅看封面大字就能独立说清视频具体讨论什么；
   - 禁用抽象包装废词（如“底层逻辑、认知觉醒、爆款密码、方法论、真相”）。
3. **事实边界兑现检查**：
   - 若稿件中某个数字属于“假设测试”（如“假设赚到 500 万怎么花”），封面与标题严禁写成“手握 500 万后我发现”，必须如实写“假设赚到 500 万”或直接提炼真实主线（如“看清随时会死 / 我拒绝背房贷 / 赎回自由时间”）。

## 二、五平台标题字数硬限、纯文字排版与专属简介规范

### 0. 生产文档纯文字、去引号与专属结束语硬规则（重中之重，本 Skill 中这些规则只在此处定义）
- 只保留纯文字与空行分段，严禁使用复杂的 Markdown 格式：不要标题井号、不要加粗星号、不要反引号、不要表格、不要分割线、不要 Emoji 数字图标，直接用自然文字分行，确保复制粘贴到平台后台时零多余符号。
- 严禁滥用引号：标题、简介、话题标签、置顶评论一律不要用反引号或双引号包裹，正文里除书名篇名必要的书名号外，尽量少用双引号和直角引号，不要给普通概念词套引号。
- 原字保留创作者专属结束语：哲思与人文视频最后一镜（终幕题词与结尾配音字幕）固定保留创作者个人结束语：以不休止的追问，找到鲜活的自我；在有限的共识里，达成无限的可能。严禁删改、拆散原意或替换成其他鸡汤收尾。
- 所有文案禁用「不……而……」「不是……而是……」「并非……而是……」句式，禁用 Emoji。

### 1. B 站（哔哩哔哩）
- **投稿标题**：`≤ 80` 字符，交代具体人物处境/测试锚点 + 反常识核心追问（给 `2` 个备选，首项标推荐）。
- **视频简介**：
  - `2～3` 句话高密度核心梗概；
  - **精确到秒的空降章节时间轴（`00:00` 格式）**：直接使用合成脚本输出的 `out/chapters.txt`（按 `60fps` 真实累加帧数计算），严禁手估编造秒数；
  - 引用典籍 / 数据来源 / 适用边界说明；
- **投稿标签**：`8～10` 个精准垂类词；
- **置顶首评**：围绕正片核心测试或追问设计 `1` 个具体可回答的评论互动问题。

### 2. 小红书视频
- **视频标题**：含标点 **严格 `≤ 20` 字符**（逐字核数并标明字符数，给 `2～3` 个备选）。
- **发布正文**：
  - 开头 `2` 句真实处境切入；
  - 中段 `3` 条结构化看点提炼；
  - 结尾 `1` 句具体处境提问 + `5～6` 个搜索长尾 `#标签`；
  - **排雷红线**：严禁出现 `.com / .io` 外链、微信号或站外导流暗语。
- **置顶首评**：轻量行动打卡或共鸣追问。

### 3. 抖音
- **作品标题**：含标点 **严格 `≤ 30` 字符**（给 `2` 个备选）。
- **作品描述**：两句话高信息密度简介 + `5` 个 `#话题标签`。
- **置顶首评**：引导观众跳转至全片最具张力的精确分秒段落（如“建议看到第 01 分 59 秒……”）并留下观点。

### 4. 微信视频号
- **作品标题**：含标点 **严格 `≤ 30` 字符**。
- **作品描述**：两句话沉静走心提炼（契合熟人社交圈“赞与推荐”转发心理）+ `5` 个 `#话题标签`。
- **置顶首评**：提炼全片最值得收藏转发的一句核心金句收尾。

### 5. 快手
- **双列推荐短标题**：含标点 **严格 `≤ 18` 字符**（纯大白话直给冲突与数字，严禁英文缩写与生僻黑话，给 `2` 个备选）。
- **作品描述**：接地气、实在算账式或掏心窝大白话描述 + **最多 `4` 个 `#话题标签`**（快手平台硬上限只能添加 4 个话题，严禁超出）。
- **置顶首评**：老铁唠嗑式直白互动提问。
