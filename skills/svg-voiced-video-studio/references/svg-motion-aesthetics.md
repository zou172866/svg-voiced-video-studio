# SVG 动态画面审美手册（v6 技术规范与质检口径）

> 先读 1 页 [美术方向](art-direction.md) 建立审美判断（核心标准：**这一帧印成杂志内页能不能用？**）。本手册承载落地的网格坐标、组件参数、动效规则、程序化质检阈值与盲审打分卡。

## 一、八条落地技术规范

### 1. 主角巨尺对比与留白连块（消灭顶部堆砌与中间空洞）
- **竖屏尺寸对比**：G1 纪念碑巨数在 `1080` 宽画布使用 `320～480px`（短数字/核心词直接铺出杂志级视觉落差）；常规画面主字 ≥ `120px`（横屏）/ ≥ `180px`（竖屏），任何标签不低于 `28px`（横屏）/ `40px`（竖屏），单屏最多 `3` 档字号。
- **主角高度与中洞硬线**：主体占安全区高度必须 **≥ `40%`**（`audit_aesthetics.py` `MIN_HERO_HEIGHT = 0.40`）；独立视觉元素 ≤ `8` 个；单幕源码 `<text>` 节点 ≤ `14` 个。
- **留白连成整块、图字下沉成组**：模式 C 竖屏（`1080×1920`）中，字幕升至 `54px` 位于 `bottom = 410px`，图形安全区为 `y = 248..1300`（高 `1052px`）。组件默认用 `bottomAnchorY(contentH, safe, 36)` 将图形底边贴近字幕上沿（图形与字幕间距 `≤ 72px`），**把整片呼吸留白统一推向画幅上方或右侧连成一整块**，彻底消灭夹在图形与字幕中间的死空（`audit_aesthetics.py` 检中洞比例 `middle_hole <= 0.24` 与空白连通聚合度 `neg_cohesion >= 0.55`）。

### 2. 画面放词，句子交给声音，字幕大号贴图且跟声变红
- **画面极简**：画面文字只放关键词、数字或原文片段（单处 ≤ `8` 字），不与字幕重复整句；中文画面字从完全显现后停满 `minReadHoldSec(text, isKeyNumber)`（`字数÷4.5+1.5s`，关键数字 `≥ 2.5s`）。
- **竖屏字幕耦合规范**：`SceneFrameShell` 竖屏默认字号 `54px`（单行约 `12` 视觉单位，左贴网格避开右侧 `140px` 交互列），位置紧邻图形下沿形成视觉整体；外壳直连 `accentAt(tSec, emphasis)`，念到 `*关键词*` 时字幕对应词以 OKLab `mixHex` 同步变红（声画同步回声；`audit_aesthetics.py` 图形区仍严格限制红焦点 `≤ 1`）。

### 3. 每模式单一展示字体与中西混排铁律
- **封面与正片强制同一款展示字体**：
  - **模式 C（商业快解说）**：封面与正片主标全部锁定多字重黑体 `STUDIO_FONTS.sans`（`Source Han Sans CN` Heavy `800～900`）+ `STUDIO_FONTS.figure`（`Bahnschrift / DIN Alternate` `lining-nums tabular-nums`），**严禁模式 C 混用衬线主标**（`audit_aesthetics.py --src` 核查）。
  - **模式 A、B（哲思长片）**：衬线体留给 A、B，封面与正片统一使用 `STUDIO_FONTS.serifMixed`（字重锁 `400～600`，`fontSynthesisWeight: 'none'`，禁 `SimSun` 伪粗膨胀）。
- **中文衬线混排拉丁字母零散开**：`STUDIO_FONTS.serifMixed` 必须把匹配拉丁衬线（`'Source Serif 4', 'Newsreader', 'Cambria', 'Times New Roman'`）排在中文字体之前；凡衬线混排拉丁字母，一律通过 `<MixedSerifText>`（SVG）或 `.latin-run`（HTML）把拉丁串 `letter-spacing` 强制设为 `0`，并全链路过 `panguSpace()` 插入 `\u2009` 光学细空格。

### 4. 朱砂红禁令与单红信息纪律
- **红只用于字、细线（≤ 3px）或紧凑朱砂方印，禁止大面积红底块**：严禁制作红底白字的 App 提示条、CTA 按钮或全宽红标签（`audit_aesthetics.py` 像素级拦截宽条实心红底按钮，同时放行红字、细线与紧凑方形朱砂印章）。
- **红随声走（OKLab 均匀过色）**：`accentAt(tSec, emphasis)` 提前 `0.12s` 亮起、念完 `0.45s` 退回墨色；图形区任意单帧红色焦点 `= 1`，`#D93B22` 只用于大字展示与印章，小号红字用 `theme.accentText`（`#C9351E`，对比度 `4.65:1`）。
- **纸面去噪**：默认关闭全部英文等宽装饰页眉（如 `ANTIGRAVITY SKILL · EP.04`）、页脚参数（如 `SWISS EDITORIAL 60FPS`）与模式 C 竖屏顶部进度/章节横条，画幅上方与左侧保持纯暖宣纸呼吸留白。

### 5. 纸面命令行与严禁大黑块（60-30-10 纪律）
- **浅纸主题严控重墨面积**：模式 B、C 保持 `≥ 60%` 纸面呼吸，单幕总墨色覆盖 `≤ 28%`，且**单块连通暗墨面积 `≤ 12%`**（`audit_aesthetics.py` 直接拦截占半屏的黑底终端卡片）。
- **命令行排在纸面上**：展示 `/boost`、`npx skills add` 等指令时，直接调用 `SwissSvgPrimitives.tsx` 的 `<PaperCommandLine>`——在暖纸面上以等宽字排印，配朱砂红光标、细下划线或无填色描边键帽（`<PaperKeycap>`），彻底告别黑底卡片。

### 6. 一张画布、系列招牌动作与物理主动作
- **整期一张画布 + 纯宣纸极简留白（模式 C 默认）**：整屏左侧与顶部保持干净纯宣纸留白（无左侧竖线/脊线、无字幕左竖杠、无顶部章节进度条，纯文字字幕与主体同轴左对齐）；分幕外壳默认 `disableMasterFade` 通过推镜（`cameraAt` / `<SingleCanvasAct>`）或匹配剪辑承接，拒绝每幕清场淡入淡出。
- **系列招牌动作（`<EditorialSealStamp>`）**：每期最关键的 `1～2` 个核心数字或判断落定时，在其旁以 `EASE_WHIP` 干脆盖下一枚精致朱砂红方印（如「实盘」「开源」「核验」「回本」），同步配 `stamp_thud` 盖章闷响。
- **每幕至少 1 个空间主动作，禁用纯淡入 PPT**：画面怎么动由旁白动词决定（推镜 `cameraAt`、纸面掀幕 `<SvgWipe>`、描边/柱条生长 `drawStroke`、墨线划断 `EditorialStrikeReveal`、计数器承接 `countTo`）；同一时刻只动一样，落定后静止；模式 C 弹簧只准用 `hero` / `swissSnap`（零回弹），离场 `0.25s` 快于进场。

### 7. 构图轮换硬门禁与结构配额
- 全片至少轮换 **`3` 种不同构图原型**，且必须包含 **至少 `1` 幕 G1 纪念碑巨数** 与 **至少 `1` 幕 G3 拓扑流图或 G4 精密数据轴**。
- **相邻幕雷同升级为硬 `FAIL`**：`audit_aesthetics.py` 计算相邻幕 `24×24` 轮廓 Dice 相似度，任意相邻一对 `≥ 0.72` 或全片 `≥ 2` 对 `≥ 0.65` 直接判 **`FAIL`**（非告警）；各幕墨色覆盖密度需有起伏（含至少 1 幕轻/空镜，目标 CV 参考 `evals/results/v6_aesthetics_calibration.json` 实测标定值）。

### 8. 纸墨听觉质感与两段式动效质检
- **纸墨拟音**：用 `page_turn`（翻纸）、`stamp_thud`（盖章闷响）、`pen_stroke`（笔尖划纸）、`ruler_drop`（直尺落桌）、`ledger_tick`（机械账本轻叩）取代 `whoosh / pop / chime`，与视觉材质完全统一（详见 [sfx_synth.py](../scripts/sfx_synth.py)，支持 `assets/sfx/<kind>.wav` 实录优先覆盖）。
- **两段式动效质检**：
  1. 渲染前：`audit_aesthetics.py --src` 静态扫描 TSX，标出「只改 `opacity` 缺乏空间位移动作」的 PPT 式入场，并校验全片 G1 / G3-G4 配额与模式字体一致性；
  2. 1K 样片渲染后：`inspect_video.py` 对真实 MP4 按 `10fps` 抽样计算每幕内容区帧差与质心位移曲线（`motion_dynamics`），确认每幕（除显式 `holdStill` 空镜外）至少存在 `1` 个结构性主动作峰，零主动作直接 `FAIL`。

## 二、六大几何 SVG 构图原型与纸面扩展原语（`assets/SwissSvgPrimitives.tsx`）

| 编号 | 构图原型 / 原语 | 复用组件与核心技法 | 适用旁白类型 |
| :--- | :--- | :--- | :--- |
| **G1** | **纪念碑巨数/巨字** | `MonumentMetric`：`320～480px`（竖屏短数）超大等高数字压住下半区 + 上方整片暖纸留白 + 收束基线 | 开场重锤、核心营收/数量/倍率落地 |
| **G2** | **非对称张力对切（65/35）** | `AsymmetricSplit`：用 `theme.paperDeep` 浅纸色差与 `1.5px` 细线做 `64:36` 不对称对照（禁对称双黑框） | 痛点 vs 解法、双产品定位差 |
| **G3** | **几何拓扑流图** | `FlowRouter`：单脉冲经菱形闸门沿折线轨道分流 `2～4` 轨，仅活跃轨高亮 | 自动路由、多智能体并发、漏斗机制 |
| **G4** | **瑞士精密数据轴** | `SwissBarAxis`：淡墨刻度与 `0` 起点基线先出 → 柱条从 `0` 生长 → 唯一主角柱亮红、竞品退灰 | 跑分对比、自动化覆盖率、成本结构 |
| **G5** | **划除与纸面掀幕** | `EditorialStrikeReveal`：墨线物理划断旧认知并降灰 + `<SvgWipe>` 原生纸面遮罩横向推开揭示真相 | 辟谣纠偏、痛点反转、规则揭秘 |
| **G6** | **极简空镜定音** | `SilentEpigraph`：墨色覆盖 `< 6%`，仅一根短领线与 `1～2` 行克制断语悬于大面积留白 | 情绪深呼吸、终幕余韵 |
| **扩展** | **纸面命令行 / 朱砂方印 / 单画布推镜** | `PaperCommandLine`（等宽字+红光标/描边键帽零黑块）、`EditorialSealStamp`（招牌方印）、`SingleCanvasAct`（单画布推镜） | CLI 安装指令、系列招牌落印、跨幕连贯 |

## 三、数据与图表画面口径（商业实盘必守）

1. **未核实数字禁止上屏**：无可靠出处的数字先向用户核实或放 `待补真实数据`；纯演示无实盘标 `示意数据`，真实案例禁标该角标。
2. **出场先后与零起点**：坐标系与刻度先出 → 柱/线从 `0` 起点长出 → 最后只高亮 `1` 个核心结论（其余退灰 `theme.faint`，直接贴标签不用图例）；确需截断纵轴必须标明 `纵轴未从 0 开始`。
3. **口径齐全、倍数验算与跨幕承接**：「涨了 9 倍」（`10×`）与「涨到 9 倍」（`9×`）必须核清；币种、单位（`token` 保留英文原词）、时间范围与累计/均摊口径齐全；同一指标跨幕展开时 `countTo()` 承接上幕终值不归零；关键数字停满 `≥ 2.5s` 并附来源与底角三行合规小字。

## 四、瑞士网格语法与模式 C 标尺

- **栏数与基线**：横屏 `1920×1080` 默认 12 栏（栏距 `24px`）；竖屏 `1080×1920` 默认 6 栏（栏距 `20px`，基线步进 `24px`），一律用 `swissGrid(safe)` 取坐标。
- **竖屏黄金成组标尺（v6）**：左侧纯宣纸留白 `72px`（零竖线干扰）；顶部 `y = 0..266` 彻底清空（无顶部进度条与英文页眉，完整清出顶部 `200px` 平台 UI 并连成整块宣纸天幕）；内容安全区 `x = 72..940`、`y = 266..1330`（高 `1064px`，右让 `140px` 避平台交互列）；`54px` 纯文字左对齐字幕轨（无左竖杠）固定 `bottom = 412px`（`y ≈ 1352..1508`，完整清出底部 `400px` 平台遮挡并与图形紧贴成组）；底角三行合规小字静默排布不加英文装饰。
- **分镜前十栏自检（每幕一行）**：必须写明 `幕号 | 原型(G1-G6，与上幕不同) | 跨幕承接 | 主角与尺幅(≥40%) | 强调词(*词*) | 空间主动作(禁纯淡入) | 留白落区(上/右整块) | 招牌/纸面元素 | 数据来源 | 转场`。

## 五、程序化硬检与对照图板独立盲审

### 1. 静态审美 + 源码动效预检
```bash
python scripts/audit_aesthetics.py out/keyframes --theme editorial --src src/scenes
```
v6 同时硬检 **10 项像素指标**（红色焦点 `≤ 1`、禁宽条红底按钮、元素数 `≤ 8`、细框线 `≤ 6`、主角高度 `≥ 40%`、浅纸总墨 `≤ 28%`、单连通暗黑块 `≤ 12%`、中洞比例 `≤ 0.24` 与空白连通度 `≥ 0.55`、密度起伏 CV、相邻幕 Dice 硬 `FAIL`）与 **7 项源码规则**（字号底线、禁 `Georgia`、防 `SimSun` 伪粗、单幕 `<text> ≤ 14`、全片 `≥1` 幕 G1 + `≥1` 幕 G3/G4、模式 C 禁混用衬线主标、纯 `opacity` 无位移动作 PPT 警告）。

### 2. 1K 样片技术 + 动效曲线终检
```bash
python scripts/inspect_video.py out/sample_1080p.mp4 --expect-size 1080x1920 --expect-fps 60 --scenes-json src/data/scenesData.json
```
在原有 6 项硬检基础上新增第 7 项 `motion_dynamics`（每幕 `10fps` 帧差与结构位移峰值曲线，无主动作直接 `FAIL`）。确认样片通过后，再用 `--scale=2 --crf=16` 超采出 4K 并复检。

### 3. 独立盲审视觉七项打分卡（必须对照正反图板）
把 `qa_sheet.png`、`qa_phone.png`、`封面_手机双列180px缩略图检验表.png` 连同 [正例对照板](../assets/reference_board_good.png) 与 [反例对照板](../assets/reference_board_bad.png) 交给**不看代码**的独立审片子 Agent，逐条给 `PASS / FIX`：
1. **杂志内页级尺幅与留白**：主角是否足够大（G1 巨数有压迫感、主角 ≥ 40%），留白是否连成上方/一侧整块而无中间空洞？
2. **绝不撞脸反例板**：有无连续同骨架清单、黑底终端卡片、宽条红底白字按钮、灰糊英文装饰页眉？
3. **纸墨材质与招牌识别**：命令行是否干净排在纸面上？画幅左侧与顶部是否保持纯宣纸干净留白（零多余竖线/竖杠/顶栏进度条）、核心落点朱砂方印是否克制锐利？
4. **字体统一与零散开**：封面与正片是否为同一款展示字体（模式 C 统一粗黑体）？混排拉丁字母间距是否紧密无 `S k i l l` 散落？
5. **图字耦合与平台防遮挡**：`54px` 字幕是否与图形紧贴成组、关键词变红是否准确、全片是否清出上 `200` / 下 `400` / 右 `140` 遮挡区？
6. **动效活度与节奏**：`qa_sheet.png` 连续采样中是否可见明显的空间推拉/擦除/生长/分流变化，且相邻幕构图有清晰起伏？
7. **封面层级与 `180px` 缩略图一眼可读**：缩略图下能否 1 秒读出超大钩子与唯一红信息焦点？双栏是否开放无框套框、无制作参数？
