# SVG 动态画面审美手册

在设计分镜、写 SVG 场景组件、审查关键帧时读取本文件。技术正确（不穿字、闭合、净距）只是底线；本手册回答的是画面好不好看、观众看不看得进去、多做几期会不会雷同。

反例取自本工作区哲思长片的真实关键帧（《湖心亭看雪》hx、《风雪孤舟》sb），可用 `scripts/audit_aesthetics.py` 复查。

---

## 一、八条核心原则

### 1. 一幕一主角
- **做法**：每幕先回答“这一幕观众该盯着哪一样东西”，只放大这一样，占内容区高度一半以上；其他元素降为淡墨细线或直接删掉。
- **数值**：主体高度 ≥ 内容区 `50%`（检查脚本下限 `25%`）；独立视觉元素 ≤ `8` 个。
- **反例**：hx S04 左右各三个小方框对照，21 个元素，观众不知道看哪一格；sb S11 五只小船排成一排，主体高度只占 `10%`。
- **依据**：格式塔图底分离，动画 12 原则中的 Staging（一次只把一个想法交代清楚）。

### 2. 画面放词，句子交给声音，给足阅读停留
- **做法**：画面文字只放关键词、数字或原文片段，单处 ≤ `8` 字；完整句子由配音和字幕承担。画面标题与字幕不能是同一句话。
- **最短停留公式**：中文画面字从**完全显现后**起算，`停留秒数 ≥ 字数 ÷ 4.5 + 1.5s`（调用 `minReadHoldSec(text, isKeyNumber)`）；关键实盘数字至少停 `2.5s`。快节奏靠**减少画面字数**，不靠压缩停留时间。
- **反例**：hx S09 画面中央“转瞬即逝的炉火，反衬出天地间无人长伴的绝对孤寂”与底部字幕同句，观众在读和听之间来回切换。
- **依据**：Mayer 冗余原则与中文扫视阅读速率模型。

### 3. 文字即画面
- **做法**：讲文本就展示文本本身，讲数据就让数字本身成为画面。古文题材把原文排成字格，镜头推到被讨论的那几个字，裂缝、圈注直接画在原字上；商业题材让关键数字以 `240px` 以上的衬线或等高字体左对齐独占画面。
- **字号**：画面主字 ≥ `120px`（横屏）/ ≥ `160px`（竖屏）；任何文字不低于 `28px`（横屏）/ `40px`（竖屏）。
- **反例**：等宽英文小标签 `TEXTUAL INQUIRY // S01`、`CRACK 01`、右侧竖排碎字，手机上只是一团灰。

### 4. 朱砂红跟着声音走，露出帧对准命中点
- **做法**：稿件定稿时由 Agent 为每句标 1 处 `*关键词*`（数字、专名或判断词），用户审稿时一并确认。合成脚本写出每个强调词的起止秒数，场景组件用 `accentAt(tSec, emphasis)` 取当前该亮的那一个，`mixHex(ink, accent, strength)` 着色。念到才变红，念完退回墨色。
- **露出对齐（`revealOn`）**：遮罩擦除或图形展开如果从命中点才启动，观众会觉得声音先到、画面慢半拍。用 `revealOn(hitSec, durSec, revealRatio)` 把转场起点往前推（擦除 `revealRatio ≈ 0.1`，光圈/裂开 `revealRatio ≈ 0.3`），让新画面首次露出的那一帧正好落在强调词起点或切点上。
- **数值**：同屏红色焦点 = `1`；提前 `0.12s` 亮起，念完后 `0.45s` 退回。章节号、边框、装饰线、时间轴圆点与横线骨架一律保持墨色 `#1A1A18` 或灰褐，仅对当前念到的唯一数字或短词上朱砂红（防止点线与文字在空间上断开触发 `accent_blobs > 1`）。
- **反例**：hx S05 同时出现 6 处红色（红框、红字、红线、红时间点），红色失去了指向作用。
- **依据**：Mayer 信号原则、时间邻近原则与视听同步感知窗。

### 5. 一张画布、弹簧选档与快离场
- **一张画布镜头移动**：一幕（或一整章）画在同一张大画布上，用 `cameraAt(tSec, keys, w, h)` 平移和推近（倍率 `1→4` 以内，时长 ≥ `0.8s`），替代淡出换卡片。幕间优先用形变或匹配剪辑承接（上一幕末尾的线头或圆点变成下一幕的坐标轴或起点）。
- **弹簧分 4 档，同类锁同档**：统一调用 `SPRING_PRESETS`（`edge` 快利落角标 / `card` 默认容器 / `hero` 高阻尼主字 / `swissSnap` 零回弹版式跳位）；**模式 C 严禁回弹弹簧，只准用 `hero` 或 `swissSnap`**。不用弹簧处用命名曲线 `EASE_SNAP`（版式跳变、擦除）、`EASE_GLIDE`（落定）、`EASE_WHIP`（快切），不写死匀速线性（时间序列匀速画线除外）。
- **离场比进场快**：进场 `0.4～0.6s`，离场 `0.2～0.3s`（`getSceneLifecycle` 默认 `exitSec = 0.25`），旧元素迅速让出舞台，不拖泥带水。
- **依据**：电影匹配剪辑（Match Cut）与二阶阻尼系统响应。

### 6. 动作有含义，一次只动一样
- **做法**：画面怎么动由旁白的动词决定：拆开→裂开，消失→擦除，对照→镜像，累积→堆叠，转折→翻面。同一时刻只有一个主动作，其余元素静止。
- **停顿处静止**：句间停顿、核心判断落地后的 `0.6～0.75s` 留白里，画面可以完全不动；数据落定后严禁继续晃动（否则观众以为数值还在变）；呼吸微动只给哲思片主角，幅度 ≤ `1.5%`。
- **依据**：动画 12 原则中的 Staging 与 Timing。

### 7. 密度要有起伏
- **做法**：排分镜时给每幕标密度：满（数据、对照）、中（主角 + 一个关键词）、空（一个点、一条线、一句原文）。全片至少 1 幕空镜，满幕后面紧跟中或空。
- **数值**：各幕墨色覆盖率的变异系数暂定 ≥ `0.45`（检查脚本提示）；空镜墨色覆盖 < `1%`，高潮幕可以 > `8%`。
- **反例**：旧片 12 幕墨色覆盖都在 `1.5%～6.5%` 之间，变异系数 `0.32～0.36`，从头到尾一样满。
- **依据**：瑞士版式尺度对比与 Mayer 连贯原则。

### 8. 线条有墨的质感
- **模式 A、B（哲思）**：主角轮廓用 `taperStroke()` 做起收笔粗细变化（最大 `4～7px`），辅助线用 `inkJitter()` 加 `1.2～2.5px` 的固定种子抖动；可按需测试开启外壳 `paperGrain`。
- **模式 C（商业）**：保持 `1.5px` 等宽墨线与直角，数字和图表是主角，不加手绘抖动。
- **禁止**：火柴人、笑脸、图标库式小人物；需要人物时用剪影或一个点代表。

## 二、数据与图表画面口径（商业实盘必守）

讲营收、增长、成本结构时，每一个视觉变化都必须编码真实数据，严禁做装饰性假图表：

1. **未核实数字禁止上屏**：没有可靠出处的数字先向用户核实，或显式放 `待补真实数据` 占位，严禁编造凑整；纯方法演示无实盘时每镜标 `示意数据`，真实实盘案例严禁标该角标。
2. **出场先后**：淡墨灰坐标系与必要刻度先出 → 柱子或折线从起点长出 → 最后只高亮 `1` 个核心结论（其余对比项退为浅灰 `#B8B2A6`，不用图例，标签直接贴在数据旁）。
3. **纵轴从 0 起算**：柱状图与面积比必须从 `0` 开始生长；确因极小波动需截断纵轴时，画面轴旁必须写明 `纵轴未从 0 开始`。
4. **倍数与算式验算**：「涨了 9 倍」（终值是初值的 `10` 倍）与「涨到原来的 9 倍」（终值是初值的 `9` 倍）必须分清；审片时实际拿图上数字验算画面结论。
5. **口径齐全与跨镜不归零**：币种（`$` / `¥`）、单位（`万` / `M` / `token`）、时间范围（`/月 MRR`、`/年 ARR`、`2025 Q4`）一处不漏；全集累计值与单次均摊值同幕或同句并列时，必须显式标清「全套评测累计」与「均摊每单」（依据：Tufte 统计诚实度，防读者心算总量乘单价产生歧义）；推近或换镜展开同一指标时，计数器必须承接上一镜终值，严禁从 `0` 重滚。
6. **停留与来源小字**：关键数字落定后至少停 `2.5s`；数据幕或终幕下方放一行来源小字（商业系列配合右下角三行风险边界贴片小字）。

## 三、瑞士网格语法与三模式风格信号表（防同质化）

### 1. 瑞士模块网格语法（`swissGrid(safe)`）
- **栏数与基线**：横屏 `1920×1080` 安全区内默认 **12 栏**（栏距 `24px`），竖屏 `1080×1920` 安全区内默认 **6 栏**（栏距 `20px`，基线步进 `24px`）。直接调用 `const grid = swissGrid(safe)` 取 `grid.colX(1..N)` 与 `grid.spanW(k)`，不手写随意坐标。
- **左对齐优于居中**：居中大字是 AI 默认模板的头号特征。标题、数据块、注释栏优先贴网格左对齐（右侧自然参差）；超大数字做视觉左对齐（微扣字形左侧空白）。网格线本身不必全程画出来，元素贴在骨子里即可。
- **以静衬跳变**：版式落定后整块静止，生命力集中在按网格跳位或遮罩擦除的那一下；章节转折处可用 `90°` 竖排短词切换阅读方向。

### 2. 三模式辨识信号与“最俗版本”避坑
每期定稿时，从所选模式挑 **2～3 个辨识信号**（其中至少 **1 个不在“最俗默认版”里**），写入 `out/定稿决策.md`：

| 模式 | 可选辨识信号（每期挑 2～3 个） | 最俗默认版（必须翻掉或写明保留理由） |
| :--- | :--- | :--- |
| **A. 深炭黑夜车哲思风** | ① 原文字格直接开裂或圈注；② 单束轨道切线穿过全章；③ 焦浓重淡清五阶墨度层次；④ 孤点拉远揭示全景尺度；⑤ 核心追问后整屏完全凝止；⑥ 竖排章名压左/右栏边 | 暗黑底居中发光圆环 + 四周贴四个英文小方框标签 + 全程匀速淡入淡出 |
| **B. 瑞士典藏暖宣账本风** | ① 左右对页结构（左列规则/算式，右列证据）；② `taperStroke` 起收笔墨线勾主物；③ 手卷式长画布横向推移；④ 单笔横线划掉旧假设露出真值；⑤ 不规则边缘小方朱印落款；⑥ 单根时间基线贯穿多幕 | 宣纸底配细线亭子/火柴人小图标 + 居中大标题 + 每幕清空舞台重摆方框 |
| **C. 瑞士暖纸媒竖屏快解说** | ① 占半屏视觉左对齐巨型等高数字；② 高亮唯一主角柱/线、其余退灰；③ 6 栏时刻表/账单逐行跳位填满；④ 大数字拉远揭示只是总账一格；⑤ 整块暖纸色块遮罩擦除换版；⑥ `90°` 竖排短词切分成本与净利 | 白底居中黑大字 + 红框套小框 + 网格细线从头画到尾 + 结尾居中盖章 |

## 四、分镜前自检（每幕一行，九栏齐备）

除 S01 外，每幕必须写清从上一幕**承接**什么元素或运动方向，禁止每幕把舞台清空重摆：

```text
S03 (~11s) | 承接：S02 底线保留右延为横轴 | 主角：$12,400 左对齐巨字（滚动→定格 3.2s） | 强调词：*12,400* | 动作：6 栏第 1 栏跳出→竞品柱退灰 | 密度：满 | 来源：TrustMRR 公开页 | 转场：数字底边缩成 S04 利润率切线
```

写不出主角、强调词、跨幕承接或真实数据来源的幕，先改分镜，不进入编码。

## 五、关键帧与成片检查

1. 静态抽帧后运行审美检查：
   ```bash
   python scripts/audit_aesthetics.py out/keyframes --theme editorial --src src/scenes
   ```
   处理红色焦点过多、元素过碎、方框过多、主角过小、全片密度太平与字号低于下限的提示；确属设计例外的在交付验收单写明理由。
2. 全片按 `--scale=2 --crf=16` 默认直出原生 4K 成片后运行技术终检（硬检 `2160x3840`［横屏 `3840x2160`］分辨率、帧数、零黑帧、`-14.0 ± 1.5 LUFS` 响度与 `-1.0 dBTP` 真峰值，并导出 `qa_sheet.png` 供独立盲审）：
   ```bash
   python scripts/inspect_video.py out/final.mp4 --expect-size 2160x3840 --expect-fps 60 --scenes-json src/data/scenesData.json
   ```
