# 纸墨拟音实录覆盖槽位（`assets/sfx/`）

`scripts/sfx_synth.py` 默认使用物理建模合成 5 种纸墨拟音；若将任意同名实录或免版权 `.wav` 放入本目录，合成管线会自动优先加载实录（自动重采样至 `32kHz` 并归一化），无需改任何代码：

- `page_turn.wav`：翻纸（幕间 / 章节转场，J-cut 对齐）
- `stamp_thud.wav`：朱砂方印盖章闷响（每期核心数字/结论落印，全片 `≤ 2` 次）
- `pen_stroke.wav`：笔尖划过纸面（划除旧认知、描边落线、重点批注）
- `ruler_drop.wav`：直尺落桌轻叩（关键词/轴线/数据条落位）
- `ledger_tick.wav`：机械账本刻度轻叩（数字滚动计数器）
